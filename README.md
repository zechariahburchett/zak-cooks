# 🍳 Zak Cooks

Welcome to the repository for **Zak Cooks**—a digital collection of tested family recipes, slow-cooker staples, holiday appetizers, and everyday cooking notes.

👉 **Live Site:** [https://zechariahburchett.github.io/zak-cooks/](https://zechariahburchett.github.io/zak-cooks/)

---

## 📖 About The Project

This site is built with [Astro](https://astro.build) using a customized version of the [AstroPaper](https://github.com/satnaing/astro-paper) theme. It automatically builds and deploys to **GitHub Pages** whenever new Markdown recipe files are pushed to the `main` branch.

### Features
* ⚡ Fast static site generation via Astro
* 📱 Mobile-friendly responsive design
* 🔍 Full-text recipe search & tag filtering
* 🌙 Light and Dark mode support

---

## 🛠️ Adding or Updating a Recipe

1. Add or edit a Markdown recipe file inside `src/content/blog/` (using standard frontmatter format).
2. Open terminal in the project root and publish live:

```bash
git add .
git commit -m "Add new recipe: <Recipe Name>"
git push origin main
```
